# Changelog

## b64 0.1.7

CRAN release: 2025-07-14

- Removes use of `.inspect_err()` which wasn’t in stable until 1.76
- Adds `xz` as a system requirement

## b64 0.1.6

CRAN release: 2025-05-19

- Enables building in offline environments
- Improves documentation
- Adds new utility function
  [`decode_as_string()`](../reference/encode.md) to decode base64
  strings directly into a string.

## b64 0.1.3

CRAN release: 2024-09-26

- Addresses non API changes
- All hard dependencies were removed
  ([\#2](https://github.com/extendr/b64/issues/2),
  [@etiennebacher](https://github.com/etiennebacher)).

## b64 0.1.0

CRAN release: 2024-01-15

- Initial CRAN submission.
